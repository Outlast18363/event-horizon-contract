Your code runs the outpost

Each work order asks for one Python function. RUN checks it against the calibration samples, which costs nothing. The amber button hands the function to the world: its return value is what the drone, the launch rail or the assay box actually does, and the ledger moves with it.

The output of one work order is the input of the next. Python 3.12 runs in your browser via Pyodide; nothing leaves this page.

Compute budget (work order ③): every loop iteration and function call costs 1 op. Built-ins that walk a collection cost one op per element: Counter(x), sorted(x), sum(x), slicing s[a:b], x in list_or_str, list.count. Comparing two dicts or lists costs 1. A crate whose scan runs past 1,000,000 ops stays unverified.

Shortcuts: Ctrl/⌘ + Enter runs calibration.
